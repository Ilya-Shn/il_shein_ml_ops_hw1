# Модель и препроцессинг

`model.cbm` — неизменённая модель CatBoost из [семинарского проекта](https://github.com/NikitaMalykhin/mts25_mlops_hw2_real_time_fraud_detection), коммит `41540d91f0cbde0106671d3eb8270403508fade4`. В ней 48 деревьев, inference выполняется на CPU в одном потоке. Порог фрода сохранён: `score > 0.98`.

`preprocessing.json` подготовлен по всем 786 431 строкам `train.csv` из [соревнования](https://www.kaggle.com/competitions/teta-ml-1-2025/data). Сохранены частотные категории (первые 50 и общая категория остальных), средние целевой переменной по категориям и временным признакам, средние числовых признаков. Используются календарные признаки, расстояние по сфере и логарифмы, как в семинарском коде. Неизвестная категория получает `cat_NAN`, отсутствующее среднее кодирование — NaN, поддерживаемый CatBoost.

Таблицы можно пересоздать без обучения модели:

```bash
pip install -r requirements.txt
python -m tools.prepare /путь/к/train.csv
```

Тренировочные данные при запуске сервиса не требуются. `examples/test.csv` содержит шесть строк из настоящего `test.csv`; имена и улицы заменены. Полные датасеты в репозиторий не включены.
